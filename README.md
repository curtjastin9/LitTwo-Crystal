# LitTwo Crystal Optimizer

LitTwo Crystal Optimizer is a Minecraft optimization mod designed to make End Crystal placement faster and smoother. It helps improve crystal usage during combat by optimizing placement speed and making crystal interactions more responsive.

## Features

- Faster End Crystal placement
- Adjustable crystal placement speed
- Optimized crystal placement behavior
- Improved combat responsiveness
- Customizable toggle and speed keybinds

## Keybinds (rebindable in Controls)

| Key | Action |
| --- | --- |
| `;` | Toggle on / off |
| `,` | Slower (more delay) |
| `.` | Faster (less delay) |
